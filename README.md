# AI-Based Government Scheme Fund Allocation Trend Analysis

## Overview

Government schemes play an important role in supporting social welfare, education, healthcare, economic development, and other public initiatives. Analyzing how funds allocated to these schemes change over time can help identify funding patterns, growth trends, fluctuations, and schemes that experience significant changes in financial support.

This project presents an **AI-Based Government Scheme Fund Allocation Trend Analysis and Performance Classification System** that analyzes government scheme financial data across multiple financial years.

The system performs **data preprocessing, feature engineering, exploratory analysis, trend classification, machine learning, Artificial Immune System (AIS) optimization, Particle Swarm Optimization (PSO), prediction, and visualization**.

The project primarily classifies the funding behavior of government schemes into different trend categories such as:

- **Increasing**
- **Decreasing**
- **Stable**
- **Fluctuating**

The project also applies **Artificial Immune System (AIS)** and **Particle Swarm Optimization (PSO)** for feature selection to identify the most useful financial indicators for trend classification.

---

## Project Objective

The main objective of this project is to develop an intelligent analytical system capable of identifying and classifying government scheme fund allocation patterns.

The major objectives are:

- Analyze government scheme funding across multiple financial years.
- Clean and preprocess financial allocation data.
- Calculate year-to-year changes in fund allocation.
- Measure overall growth and percentage growth.
- Identify increasing, decreasing, stable, and fluctuating funding patterns.
- Generate statistical and trend-based features.
- Train machine learning models for funding trend classification.
- Apply Artificial Immune System optimization for feature selection.
- Apply Particle Swarm Optimization for feature selection.
- Compare baseline and optimized machine learning models.
- Generate predictions and analytical reports.
- Visualize fund allocation trends and classification results.
- Save trained models and project configuration files for future use.
